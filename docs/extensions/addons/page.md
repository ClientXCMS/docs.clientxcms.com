# Page
The Page addon allows you to create custom pages.

## Configuration
You can manage the page configuration in `Admin Panel` > `Settings` > `Extension Settings` > `Page` > `Create`

![img](/img/next_gen/extensions/addons/page/configuration.png)

Here you can create your pages.

**Title**: Page title

**Slug**: Your page link. e.g.: thank-us for https://your-client-area.com/thank-us.

**Status**: Page status.

**Content**: Page content.

## Management Panel
![img](/img/next_gen/extensions/addons/page/gestion.png)

Here, you can see all pages that have been created. You can also edit or delete them.
