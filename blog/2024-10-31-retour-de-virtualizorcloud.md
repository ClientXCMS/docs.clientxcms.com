# VirtualizorCloud Returns
We are happy to announce the return of the **VirtualizorCloud** module for ClientXCMS! 🚀
![VirtualizorCloud](/img/blog/retour-de-virtualizorcloud/image.png)
<!-- truncate -->
## What is VirtualizorCloud?
VirtualizorCloud is a module implementing the VirtualizorCloud solution, allowing your clients to create and manage their own virtual servers through their reseller package. This module offers an intuitive interface and advanced features for an optimal user experience.

## Key Features
- `➕` **Virtual Server Creation**: Allow your clients to create and manage their own virtual servers.
- `➕` **Resource Management**: Track and manage resources allocated to each virtual server.
- `➕` **Intuitive User Interface**: A simple and efficient interface for easy server management.
- `➕` **Quick Reinstallation**: Allow your clients to reinstall their server in just a few clicks.
- `➕` **Server Import**: Easily import existing servers into the VirtualizorCloud module.

## How to Use It?
You can find the complete documentation for the VirtualizorCloud module on our [official documentation](/extensions/modules/VirtualizorCloud). This documentation will guide you through the installation, configuration, and usage steps of the module.
