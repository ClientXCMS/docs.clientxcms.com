# v2.14.10

We are pleased to announce the release of version **2.14.10** of ClientXCMS!
![version 2.14.10](/img/blog/versions/v2.14.10.png)

<!-- truncate -->

## Additions

- ➕ Support for the customer reviews addon for product badges
- ➕ Implementation of a dynamic preview when configuring a product in the cart

## Changes

- 🔄 Extensions can be re-downloaded without a new update

## Fixes

- 🔧 The expiration email was no longer being sent
- 🔧 Version backup for themes
- 🔧 Wrong placeholder on client API routes
- 🔧 Inconsistent phone number formatting during registration

## Security

- 🔒 Added custom cookie management for the CSRF token
- 🔒 Added a parameter to allow/disallow registration of emails with "+"
