# v2.14.1**

Nous sommes ravis de vous annoncer la sortie de la version **v2.14.1** de ClientXCMS, qui apporte de nombreuses améliorations et nouvelles fonctionnalités pour enrichir votre expérience utilisateur.
![version v2.14.1](/img/blog/versions/v2.14.1.png)

- 🔄 Modification du type de champ dans la réinitialisation du mot de passe vers un champ type password
- 🔧 Validation sur mobile pour l'expiration d'un service
