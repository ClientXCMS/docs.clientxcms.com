# v2.13.0 - Multi language update**

We are pleased to announce the release of version **v2.13.0** of ClientXCMS, which brings numerous improvements and new features to enhance your user experience.
![version v2.13.0](/img/blog/versions/v2.13.0.png)

<!-- truncate -->

- ➕ Added payment method page
- ➕ Added automatic payments via Stripe
- ➕ Added copy-paste field on groups
- ➕ Added field to use image as background on a group
- ➕ Added dedicated account confirmation page
- ➕ Added dedicated account creation confirmation page
- ➕ Added charts & statistics on the earnings page
- ➕ Added delivery and expiration date on service orders
- ➕ Added multi-language support on client area in English, Spanish, and French
- ➕ Added "Background Addition" extension
- ➕ Added table with payment ID and date on an invoice
- ➕ Added global balance on admin dashboard
- ➕ Added ability to translate products, groups, menus, and various settings
- ➕ Added %firstname% %lastname% %email% and %fullname% variables on greetings when sending emails
- ➕ Added smart quick search in administration
- ➕ Added search field on action history
- 🔄 Changed subdomain to "Subdomain host"
- 🔄 Modified HTML container in administration to gain more space
- 🔄 Modified phone field now optional at registration and unique per account
- 🔄 Modified action buttons on users to a global action menu
- 📦 Optimized services, invoices, tickets page in administration
- 📦 Improved invoice PDF
- 🔒 Improved security captchas
