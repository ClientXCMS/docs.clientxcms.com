Hello everyone,

The year 2025 marks a **major turning point** in the history of ClientXCMS.
After the end of life of the first version in late 2024, and the first full year of the **NextGen** version, the project reached a decisive milestone: **its transition to open source** in September 2025.

This choice was not trivial. It profoundly transformed the way the project evolves, both technically and community-wise. Find in this article a summary of the improvements made and the new features of version **v2.15**.

## API Improvements, New Payment Platforms, and Enhanced Security

The upcoming version **v2.15**, scheduled for mid-January 2026, marks an important advancement on the API side and security improvements that enhance the user experience.

### Administration API
Many endpoints have been added:
- tickets,
- departments,
- coupons,
- servers,
- action histories,
- subdomains

which greatly improves remote access to data via the API.

![image](/img/blog/bonne-annee-2026/api-admin.png)

### Client API
The client API will also make its appearance with v2.15:
- authentication (login / register / reset password),
- invoices,
- tickets,
- services.

It will allow retrieving data for the currently authenticated client.

This API opens the way to new uses:
- Discord bots synchronized with services,
- external tools,
- custom dashboards,
- or even **an entirely custom front-end**, with ClientXCMS used only as a backend.

We won't say too much... but this opens up many possibilities.

![api](/img/blog/bonne-annee-2026/api-client.png)

### GDPR Compliance: Complete Client Account Deletion

With **v2.15**, ClientXCMS will allow complete deletion of a client account, while retaining mandatory billing data, thanks to a clear separation between client information and invoices.

An essential advancement for GDPR compliance and user trust.

![deletion](/img/blog/bonne-annee-2026/delete_account.png)


### Enhanced Security: Security Questions

The security of your data and that of your clients is our priority. ClientXCMS will introduce **security questions**, an additional layer of protection for client and administrator accounts. In case of suspicious activity or sensitive procedures, this tool ensures user identity verification in a simple and effective way.

![questions](/img/blog/bonne-annee-2026/security_questions.png)

### Cancellation Management and Statistics

To better understand your clients' departures, ClientXCMS now offers advanced cancellation reason management. Administrators can not only define custom reasons but also access detailed statistics. This valuable data helps identify friction points and adjust your offerings accordingly.

![Cancellation analysis](/img/next_gen/settings/provisioning/cancellation_reasons/index_admin.png)

### New Payment Methods

Version v2.15 (mid-January 2026) will integrate **three new payment platforms**:
- Mollie (with automatic payments, like Stripe),
- Square,
- SumUp.

These solutions enrich the ecosystem and facilitate the adoption of ClientXCMS in different contexts.

Feel free to suggest payment platforms via the [idea platform](https://ideas.clientxcms.com).

![gateway](/img/blog/bonne-annee-2026/gateways.png)

## Extensions

A quick overview of the new available extensions and various improvements to existing extensions.

### Native Pelican Integration

Developed by **@FreezMod**, the Pelican module was highly requested and stands out as a choice solution for modern hosts seeking automation. It enables smooth and automatic server management, from sales to delivery, while offering fine-grained resource customization. A simplified client experience, designed for efficiency with the ability to reinstall a server via the client panel or customize eggs.

![pelican](https://share.byh.fr/files/GvtQAX5hR6Uyd7a-panel_client_service.png)

### Announcements Addon

The Announcements addon, also created by **@FreezMod**, transforms how you interact with your community. A true communication hub, it brings together news, blog posts, and official announcements within a modern and powerful tool. Thanks to its SEO optimization, detailed statistics, and integration via REST API or RSS feed, it becomes the pillar of your content strategy.

![announcements](https://share.byh.fr/files/8TzxaQrPiAvV6wn-CTXCMS_Addon_Announcements.gif)

### New Feature: Integrated noVNC Console

The **noVNC** console is now accessible directly from the client area, with secure access limited only to the client's VM.

A long-postponed element, now fully integrated into the Proxmox module.

![noVNC](/img/blog/bonne-annee-2026/noVNC.png)

You just need to add a Proxmox role `CustomerPanel` with the `VM.Console` permission.


### Pterodactyl Module: Intelligent Diagnostics

A new **diagnostician** now allows you to precisely explain the error:

> *"No node satisfying the requirements for automatic deployment were found"*

By clearly indicating **what is missing**, thus avoiding long unnecessary time losses.
