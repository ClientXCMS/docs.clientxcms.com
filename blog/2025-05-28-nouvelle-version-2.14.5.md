# v2.14.5 - Help Center Improvement

We are pleased to announce the release of version **v2.14.5** of ClientXCMS, which brings many improvements and new features to enrich your user experience.
![version v2.14.5](/img/blog/versions/v2.14.5.png)

<!-- truncate -->

- ➕ Added ticket closure reason
- ➕ Ability to see if a ticket response has been viewed only via administration
- ➕ Ability to edit a response when replying to a ticket
- ➕ Ability to delete a ticket response
- ➕ Ability to add internal comments on tickets
- ➕ Ability to manage support department permissions
- ➕ Ability to assign a ticket to staff
- ➕ Added UUID on tickets, services, and invoices
- ➕ Trial addon
- ➕ Added international format phone number input
- ➕ Added Sitemap addon to facilitate sitemap.xml creation
- ➕ Added hidden state on services
- ➕ Added filter on client detail page
- ➕ Added shortcut link to external transaction details (PayPal, Stripe)
- ➕ Added ability to manage API keys
- 🔄 Different colors based on ticket priority
- 🔄 Changed service price storage type with ability for more prices
- 🔄 Changed sections interface
- 🔄 Changed service creation and display interface
- 🔄 Moved "authorized mode" option to theme settings
- 🔄 Visual modification of support pages
- 🔄 Dynamic client search via XHR
- 🔄 [Proxmox] Display of all IPs assigned to a service
