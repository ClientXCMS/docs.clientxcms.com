# v2.14.3 - Contact Update

We are pleased to announce the release of version **v2.14.3** of ClientXCMS, which brings many improvements and new features to enrich your user experience.
![version v2.14.3](/img/blog/versions/v2.14.3.png)

<!-- truncate -->

- ➕ New menu system with more configuration & ability to create submenus on Astro & Wave themes
- ➕ Contact addon
- ➕ Added quick access buttons for services/invoices/tickets on client detail page
- ➕ Ability to filter by product category in services
- ➕ Added warning about pricing and terms changes during an upgrade
- ➕ Ability to create uniform descriptions via metadata. See more https://cdn.clientxcms.com/ressources/simulator/
- ➕ Automatic login on Plesk via administration as administrator
- ➕ Ability to add images to a product
- ➕ Notification on ban or suspension with ability to create a support ticket
- ➕ Login attempt history in action history
- ➕ HTML code editor support on products
- ➕ Added Call to Action in administration to better guide new users
- ➕ Added quick actions on client editing
- 🔄 Changed confirmation popup in administration
- 🔄 PteroBox module improvement
- 🔄 Astro & Wave themes improvement
- 🔄 Menu system modification
- 🔧 PayPal VAT issue
- 🔧 Filter in client-side services
