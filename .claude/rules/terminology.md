# Terminologie

- **Extension** est le terme générique qui désigne l'ensemble : addon + module + thème. Ne pas utiliser "extension" comme synonyme d'un seul des trois.
- **Addon**, **module**, **thème** : trois catégories distinctes, à ne jamais employer l'une pour l'autre. Nommer précisément celle dont on parle plutôt que le terme générique dès que le propos ne concerne qu'une catégorie.
- Un même concept garde le même nom sur toute la doc et dans les deux locales (voir la parité i18n) : pas de synonyme variable d'une page à l'autre pour désigner la même chose.
