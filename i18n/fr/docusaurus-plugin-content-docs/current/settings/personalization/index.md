# Personnalisation

Dans **CLIENTXCMS**, la **personnalisation** est la clé pour **créer une identité unique** et **offrir une expérience de marque cohérente** à vos clients. <br/>
L'objectif est stratégique : **adapter visuellement votre plateforme** à votre image de marque, **optimiser l'expérience utilisateur** et **renforcer la reconnaissance de votre entreprise**. Une personnalisation réussie transforme une plateforme générique en vitrine professionnelle distinctive qui inspire confiance et fidélise vos clients.

Cette section regroupe tous les outils pour personnaliser l'apparence, la navigation, le contenu et l'optimisation de votre espace client.

Vous pouvez accéder aux options de personnalisation depuis :

`Paramètres` > `Personnalisation`
